# ✦ TH+ — TrueHard 与更多

**适用于 Mindustry v153 的高难度生存模组。**

语言：English (README.md) · Русский (README.ru.md) · Українська (README.uk.md)

## 功能

### 🧬 携带者
- 启用后，符合条件的敌人有 **50% 概率**变成携带者。
- 携带者死亡时，有 **50% 概率**生成 **5 个相同类型的单位**。
- 携带者及后代移动更慢、装填更慢。玩家控制的单位和盟友不会变成携带者。
- 玩家控制的单位在切换/复活后有机会获得独立的 Vika 变异（当前脚本概率为 20%）。

### ⚡ “飞逝结局”
- 首先进行 **8 秒**的能神经元倒计时，随后恢复生命并获得 **8 秒**强化。
- 效果：移动速度 +25%、装填速度 +10%、伤害 +8%、建造速度 ×30，并获得强力再生。
- 强化结束后角色最终死亡。

### ☠️ TrueHard
- 游戏界面显示 **3 次生命**。
- 玩家及盟友：最大生命值 −50%。敌人：生命值 +50%、伤害 +10%。
- 核心统计 5 次不同的敌方弹丸命中。第 5 次命中后核心被标记为摧毁；之后玩家下一次死亡会导致区域失败，即使仍有剩余生命。

## 安装

1. 从仓库的 **Releases** 页面下载 ZIP，或将模组文件打包为 ZIP，并确保 mod.hjson 位于压缩包根目录。
2. 在 Mindustry 的模组菜单中导入 ZIP。
3. 启用 **TH+ — TrueHard & More**，在主菜单打开 TH+ 按钮并启用所需模式。

## 兼容性与测试

目标版本：**Mindustry v153**。静态检查不能替代游戏内测试；尤其需要验证死亡/复活流程和核心命中拦截。报告错误时请附上游戏日志。
