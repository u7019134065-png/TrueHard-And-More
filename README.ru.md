# ✦ TH+ — TrueHard и ещё

**Мод усложнения выживания для Mindustry v153.**

Языки: English (README.md) · Українська (README.uk.md) · 简体中文 (README.zh-CN.md)

## Возможности

### 🧬 Самки-переносчики
- При включённой механике у подходящего врага есть **50% шанс** стать самкой-переносчиком.
- После смерти самки есть **50% шанс** выпустить **пять юнитов её типа**.
- Самки и потомки медленнее передвигаются и перезаряжаются. Свои и союзные юниты исключены из мутации переносчика.
- Отдельная мутация «Вика» может появиться у управляемого игроком юнита после смены/возрождения (20% в текущем скрипте).

### ⚡ «Летучий исход»
- Сначала идёт **8-секундный** отсчёт энергонейронов. Затем восстанавливается здоровье и на **8 секунд** включается усиление.
- Эффекты: скорость +25%, скорострельность +10%, урон +8%, строительство ×30 и мощная регенерация.
- По окончании эффекта персонаж окончательно погибает.

### ☠️ TrueHard
- В игровом интерфейсе отображаются **три жизни**.
- Игрок и союзные юниты: −50% максимального здоровья. Враги: +50% здоровья и +10% урона.
- Ядро считает пять разных попаданий вражеских снарядов. После пятого попадания оно считается уничтоженным; следующая смерть игрока приводит к поражению сектора даже при оставшейся жизни.

## Установка

1. Скачай ZIP со страницы **Releases** или создай ZIP из файлов мода так, чтобы mod.hjson находился в корне архива.
2. Импортируй ZIP через меню модов Mindustry.
3. Включи **TH+ — TrueHard & More**, открой кнопку TH+ в главном меню и включи нужные режимы.

## Совместимость и тестирование

Целевая версия — **Mindustry v153**. Статическая проверка не заменяет тестирование внутри игры; особенно важно проверить последовательность смерти/возрождения и перехват попаданий по ядру. При ошибке приложи журнал игры.
